# GitHub Steps

1. Create a new GitHub repository.
2. Name it `arcade-duel-clean`.
3. Do not add a README on GitHub because this project already has one.
4. Open terminal in this folder and run:

```bash
git init
git add .
git commit -m "Initial version of Arcade Duel"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/arcade-duel-clean.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

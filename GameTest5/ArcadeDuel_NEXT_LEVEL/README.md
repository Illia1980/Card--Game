# Arcade Duel NEXT LEVEL

A polished online arcade project with:

- Durak inspired by classic mobile Durak table layouts
- Chess with legal move highlighting
- Checkers with legal move highlighting
- Play vs Bot
- Play with Friend using room code / invite link
- Restart and Main Menu buttons after the end of the game
- Short tips/rules instead of long text blocks
- Cleaner UI, smoother animations and a more game-like Durak table

## Important

Do not open `public/index.html` directly.
Do not use WebStorm preview / `localhost:63342`.

Run the server and open:

```text
http://localhost:3000
```

## Local start

```powershell
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Windows easy start

Double click:

```text
START_GAME.bat
```

## Online play with a friend

For a friend from another house, upload the project to GitHub and deploy it on Render.
GitHub Pages alone is not enough because this project uses `server.js`.

## Notes

The Durak screen is inspired by the feeling of Durak Online, but it uses original CSS cards and original interface elements.
